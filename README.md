# CREDITS

**A K-pop music credits and creator archive.**

CREDITS is a web-based archive project designed to explore the people behind K-pop music through an interactive, retro-inspired desktop interface.

## Project Overview

The project brings together music credits, artist information, and creator profiles in one browsable archive.

Its interface takes inspiration from classic macOS Finder and early social networking experiences, combining a familiar desktop metaphor with an interactive creator archive.

## Key Features

- **Music Archive** — Browse K-pop music credits and related information.
- **Creator Archive** — Explore profiles of music creators and their contributions.
- **Creator Wall** — Interactive creator pages with wall posts and comments.
- **Finder-inspired Interface** — A retro desktop-style navigation experience.
- **Responsive Layout** — Adapted for both desktop and mobile screens.
- **Navigation State** — Preserves navigation and scroll positions when moving between archive pages.
- **Anonymous Comments** — Supabase-powered anonymous authentication for wall interactions.
